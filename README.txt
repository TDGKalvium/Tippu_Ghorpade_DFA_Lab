HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Enter a binary string such as 101 or 1101.
4. Click “Run DFA simulation”.
5. Click “Next step” to animate the state-by-state processing.

FEATURES
- Responsive dark dashboard UI
- Interactive DFA state diagram
- Input validation for binary alphabet {0,1}
- Accepted/rejected results
- Transition trace with step controls
- Sample inputs and reset/clear controls
- No install, server, or external library required

LANGUAGE
L = { w in {0,1}* | w ends with 01 }
